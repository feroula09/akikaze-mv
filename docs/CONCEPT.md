# 《秋風恋歌》MV 構想

原曲：秋風恋歌 / DeZI：R ・ 4:55（音樂到 4:40.12 結束）・ 102 BPM ・ 名詞依 `GLOSSARY.md`。
時間與小節取自 `analysis/audio.json`、`analysis/lyrics_mv.lrc`（`b33` = 第 33 小節）。

## 主題（thesis）

**歌被風帶成落葉。** 千鶴唱過的**手毬歌**，化成一片片被風吹落的楓葉，從天上落到小夜身上。
聽得見歌的地方就看得見葉子；歌越響，葉越多。最後副歌時，葉子在兩人之間連成一條線，那就是歌本身。

## Logline

大正時代的晚秋，小夜一個人走在兩人曾一起走過的石板小徑，嘴裡哼著已過世的千鶴教她的手毬歌。
每哼一句就落下一片楓葉。時雨落了又停，千鶴從天上對她說「泣かないで、顔上げて」。
小夜抬起頭，滿天紅楓連成一線；時雨化成**風花**，畫面轉白，只留下一對夾在和紙裡的**つがいの楓**。

## 形狀與象徵

- **主形狀：楓葉落下的弧線**（ひらひら的左右擺盪）。轉場、文字進場、鏡頭移動都沿這條弧線走。
- **次形狀：時雨的斜線。** 雨＝現在、悲傷；雨停或雨變雪＝被接住。
- **つがいの楓**（紅楓＝小夜、綠楓＝千鶴）：每次出現都有狀態變化。片頭兩片相遇又被吹散；Chorus 1 在空中互繞；Chorus 2 只剩紅楓，綠楓在雨中看不見；Last chorus 滿天紅楓裡出現一片綠楓，葉子連成線；片尾兩片夾在和紙裡成了押し葉。
- **手毬／手毬歌**：千鶴的記憶線索。回憶段裡她拍手毬；現在段裡手毬躺在小徑邊、褪了色；Bridge 千鶴手上的手毬又是新的。
- **材質：和紙＋水彩暈染。** 轉場用水彩在和紙上暈開（墨暈、雨水把畫面化開），不用玻璃或光。

## 角色（摘要，完整設定在 `docs/CHARACTER.md`，下一階段）

- **小夜**：大正女學生，矢絣和服、海老茶袴、黑長髮配紅緞帶。隨身物是一顆褪色的手毬（千鶴的）。動態道具是紅緞帶，在風中飄。
- **千鶴**：淡白或淡綠和服、栗色編髮、手拿手毬，略帶透明與光暈。她只在回憶段與 Bridge 之後以實體出現，其餘時間只以綠楓、歌聲（手寫字）出現。
- 兩人都是原創角色。千鶴與綠楓相關素材去背時用洋紅色鍵（`#FF00FF`）。

## 文字聲音（JIZURA＋自訂）

只放日文原詞。主歌用直排明朝（Shippori Mincho B1／Zen Old Mincho），キメ句用筆文字（Yuji Syuku），
**千鶴的話（Bridge 兩句）用手寫體（Klee One）**，像她留下的信。文字是和紙上的墨色（深色字配淺色畫面），
Break 與時雨鏡頭才用淺色字。排除不透明字卡與花俏版型。

## 與示範作品《残光》的差異

| 軸 | 《残光》 | 本片 |
|---|---|---|
| 世界 | 現代郊外、平交道 | 大正～昭和初期和風山間小徑 |
| 時間弧 | 黃昏 → 夜 → 黎明（一天） | 夏末 → 晚秋 → 初雪（季節） |
| 曝光 | 低調夜景 | 高調日間、陰天 |
| 色彩 | 晚霞琥珀／紫 | 和紙白、朽葉紅褐、時雨灰藍、紅楓 |
| 主形狀 | 圓（光） | 楓葉落下的弧線、雨的斜線 |
| 材質 | 玻璃與光 | 和紙與水彩 |
| 線條 | 粗筆壓線稿 | 細墨線 |
| 角色 | 一位戴耳機的歌手 | 兩位大正女孩，一生一死 |
| 3D | 漢字街道、平交道環繞 | 石板小徑長鏡頭、紅楓漫天穿梭 |
